AVI'S SIERRA HIKES

Open index.html to view the website.

FILES
index.html: Home page
 gallery.html: Gallery page
about.html: About Me page
style.css: Shared styles
images/: Six hiking photos

HOW THE ASSIGNMENT REQUIREMENTS ARE MET
Semantic HTML: header, nav, main, section, figure, figcaption, footer.
Flexbox: Navigation bar in style.css.
CSS Grid: Photo gallery in style.css.
Responsive design: Viewport tag, fluid images, and a 600px media query.
Navigation: The same three links appear on every page.
Accessibility: Image alt text, readable colors, and visible keyboard focus.

PUBLISHING
Upload this folder to Netlify as a static site. No build command is needed.
The published folder must contain index.html at its top level.
After publishing, check all three pages and submit the public Netlify URL.
